# Bakery Billing System

A web-based Bakery Billing System developed using ASP.NET Web Forms and SQL Server.

## Technologies Used

- ASP.NET Web Forms
- C#
- SQL Server
- HTML
- CSS
- Bootstrap

## Main Features

- User Login
- Bakery Billing
- Bill Generation
- Customer/Billing Information
- SQL Server Database Integration

## Project Type

MCA Tiny Project
